Front-end is an industry full of myths. This memo explains why frontend engineering is as technical as backend work and lists core responsibilities and misconceptions.

- We architect user experiences (UX)
- We handle cross-browser compatibility
- We optimize performance and Core Web Vitals
- We integrate with backend services and manage async flows
- We use build tooling, compilers, and automated pipelines
- We are responsible for front-end security (XSS, CSRF, input validation)

Front-end is every bit as technical and essential as back-end engineering.
